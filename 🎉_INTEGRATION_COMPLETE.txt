⚙️  TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════════

  Architecture: Server-Extension Polling Model
  • Extension polls server every 1 second
  • Server queues commands as they're generated
  • Extension executes, sends results back
  • Dashboard updates via Server-Sent Events

  Performance:
  • Command latency: ~1 second (polling interval)
  • Screenshot: ~2-3 seconds
  • Form analysis: ~3-5 seconds
  • Per job: ~10-20 seconds total

  Security:
  • Session IDs are random UUIDs
  • localhost-only (no external access)
  • In-memory commands (ephemeral)
  • Production: add authentication headers
